# The graph model goes into `implement`; there is no second execution skill

Proposed twice and rejected twice: a separate `implement-swarm`, and a separate
`plan-swarm`. Either would duplicate the whole shared frame — the gates, the
reports, the contracts, the fact/decision protocol — and the two copies diverge
at the first edit.

The project's own skill-authoring doctrine
(`skills/writing-great-skills/SKILL.md:67`) permits a split by invocation or by
sequence, and not by parameter. A "swarm variant" of an existing skill is a split
by parameter. It is recorded here because it has been proposed twice and will be
proposed again.
